          cpp.wasm is a thin layer over other people’s work. These are the projects that make compiling and running C++ in a browser tab possible.
          

    
          Compiler and runtime
          
      
          
        
          wasm-clang by Ben Smith (binji)
          
        Apache 2.0
        
          The prebuilt Clang, wasm-ld, in-memory file system and sysroot this app downloads. Ben originally published them on binji.github.io; cpp.wasm loads copies from src/vendors/wasm-clang/ on its own server. The worker’s WASI host, file-system glue and tar reader are adapted from its shared.js. Ben presented the project at CppCon 2019.
          
      
          
      
          
        
          memfs by Ben Smith, in his LLVM fork
          
        Apache 2.0
        
          The in-memory file system, itself compiled to WebAssembly, that holds your source file, the standard headers and the build output while clang and wasm-ld run.
          
      
          
      
          
        
          Clang and LLD 8.0.1 by the LLVM project
          
        UIUC (NCSA)
        
          The C++ compiler and the WebAssembly linker. Both run here as WebAssembly programs themselves.
          
      
          
      
          
        
          libc++ and libc++abi by the LLVM project
          
        MIT or UIUC
        
          The C++ standard library your programs link against: containers, algorithms, iostreams and the rest.
          
      
          
      
          
        
          wasi-libc by the WebAssembly community, based on musl by Rich Felker and contributors
          
        Apache 2.0 / MIT
        
          The C library underneath libc++. It turns calls like printf and scanf into WASI system calls that the page answers.
          
      
          

    
          Editor and type
          
      
          
        
          clang-format (wasm-fmt) by magic-akari, built from LLVM’s clang-format
          
        MIT / Apache 2.0
        
          Powers the Format button. LLVM’s clang-format compiled to WebAssembly, loaded from src/vendors/clang-format/ the first time you format.
          
      
          
      
          
        
          CodeMirror 6 by Marijn Haverbeke and contributors
          
        MIT
        
          The code editor and the recording player, with C++ highlighting, bracket matching and auto-closing brackets. Bundled in src/vendors/editor/.
          
      
          
      
          
        
          IBM Plex Sans and Plex Mono by Mike Abbink and Bold Monday for IBM
          
        SIL OFL 1.1
        
          The interface and code typefaces, bundled in src/vendors/ibm-plex/ from Fontsource.
          
      
          

    
          Collaboration
          
      
          
        
          Yjs, y-codemirror.next and y-protocols by Kevin Jahns and contributors
          
        MIT
        
          The shared documents behind rooms: edits from everyone merge without conflicts, and other people’s cursors show in the editor.
          
      
          
      
          
        
          Trystero by Dan Motzenbecker and contributors
          
        MIT
        
          Connects the browsers in a room directly over WebRTC, finding each other through public Nostr relays. Bundled with CodeMirror and the libraries above in src/vendors/editor/.
          
      
          

    
          Hosting and files
          
      
          
        
          fflate 0.8.3 by Arjun Barrett
          
        MIT
        
          Reads and writes the zip files for Import and Export. Bundled in src/vendors/fflate/.
          
      
          
      
          
        
          coi-serviceworker by Guido Zuidhof and contributors
          
        MIT
        
          A small service worker that adds the cross-origin isolation headers interactive mode needs, on hosts like GitHub Pages that can’t send them.
          
      
          

    
          Ideas and fixes
          
      
          
        
          EduOJ wasm-clang by littlebear0729 and leoleoasd
          
        MIT / Apache 2.0
        
          Their stdin work, proposed upstream in wasm-clang pull request 6, was the starting point for how this app feeds the Input pane to your program.
          
      
          

    
          Code adapted from wasm-clang keeps its Apache 2.0 notice in src/js/worker.js. Each project above is distributed under its own license; follow the links for the full terms.

    Toolchain source
    
          
      
          Clang 8, wasm-ld, the in-memory file system and the libc++ sysroot are fetched from this folder: by default src/vendors/wasm-clang/ next to this page. It must contain the files clang, lld, memfs and sysroot.tar. A full URL to another server also works if that server allows cross-origin requests.
